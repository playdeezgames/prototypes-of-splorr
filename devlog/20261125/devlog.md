**Five type-ins from August 1979**

*SoftSide* magazine's August 1979 issue printed five programs to type in: Melt Down, Shooting Gallery, Cryptogram, a Morse Code Tutor and Storybook. All five are here, remade for the browser.

- **Melt Down**: nine meters, sixteen disasters, five levels. Every command trades one problem for another.
- **Shooting Gallery**: twenty shots, four rows, one arrow worth a hundred.
- **Cryptogram**: fifty sayings to crack, hints if you need them, a timer if you want one.
- **Morse Code Tutor**: now a metaphor with levels, lives and streaks, plus a keyer and a buddy mode.
- **Storybook**: a toy. Ten questions, then a picture story about the one who answered them.

They are prototypes. Tell me which one deserves more.

The latest version is always at https://playdeezgames.github.io/prototypes-of-splorr/.
