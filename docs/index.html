SoftSide Prototypes

New takes on the type-in programs from SoftSide magazine, August 1979, by TheGrumpyGameDev. Code and words made by an AI agent (Claude Code) at the author's direction.

  • Melt Down: keep a failing reactor from melting down (after Michael Winter).
  • Shooting Gallery: twenty shots at a carnival gallery (after Frank B. Rowlett, Jr.).
  • Cryptogram: crack a saying in a letter-substitution code (after Rik Pierce).
  • Morse Code Tutor: learn Morse code by ear, level by level (after Donald E. Smith).
  • Storybook (a toy): a picture story starring the child reading it (after Otto Hansen).

Keyboard, mouse or touch. Best scores are kept in your browser.
