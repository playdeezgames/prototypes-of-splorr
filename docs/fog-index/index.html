Fog Index, a prototype by TheGrumpyGameDev after "Fog Index" by Rev. George Blank (SoftSide, March 1979). Syllables are counted by rule, so the index is an estimate. Samples: the King James Bible, Lincoln and the Declaration of Independence (public domain). Code and words made by an AI agent (Claude Code) at the author's direction. Font: Public Pixel by GGBotNet (CC0). Feedback by LootLocker.
