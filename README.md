# SoftSide prototypes

Play: https://playdeezgames.github.io/prototypes-of-splorr/ (GitHub Pages, served from `docs/` on `main`; refresh with `tools/pages.sh`, then commit and push).

A folder for prototyping games, started November 15, 2026. The first batch are new takes on the five type-in programs in *SoftSide* magazine, Vol. 1 No. 11 (August 1979): Melt Down, Shooting Gallery, Cryptogram, Morse Code Tutor (gamified) and Storybook (a toy). The listings are catalogued in `sources/softside-v1n11/LISTINGS.md`. The second batch (November 18, 2026) takes all five listings from the first issue, Vol. 1 No. 1 (October 1978): Pillbox, Gunnery Mate (after "Death Star", renamed and given its own setting), State Capital Quiz (gamified), Cribbage, and Calculator (a tool); see `sources/softside-v1n01/LISTINGS.md`. The third batch (November 20, 2026) takes all four listings from the second issue, Vol. 1 No. 2 (November 1978): Troll's Gold, End Zone (football, with a computer coach added), Shopping List (a tool) and Octal to Hex (a tool); see `sources/softside-v1n02/LISTINGS.md`. The fourth batch (November 22, 2026) takes all six listings from the third issue, Vol. 1 No. 3 (December 1978): Santa Paravia (after "Santa Paravia en Fiumaccio", with computer rulers added), Spelling Bee (gamified), Biorhythms (a toy), Mortgage, Ham Shack Clock (after "Six Million Dollar [10K] Clock") and Chess Clock (tools); see `sources/softside-v1n03/LISTINGS.md`. The fifth batch (November 23, 2026) takes all four listings from the fourth issue, Vol. 1 No. 4 (January 1979): 'Round the Horn (a clipper race round Cape Horn, with computer captains added), Ten Pin Bowling (with up to four bowlers and computer bowlers added), Kiddy Slot and Comput-A-Sketch (toys); see `sources/softside-v1n04/LISTINGS.md`. The sixth batch (November 25, 2026) takes two listings from the fifth issue, Vol. 1 No. 5 (February 1979): Prize Board (after "Concentration", renamed, with a computer contestant added) and Elements Quiz (gamified, with today's 118 elements and a periodic table to study); see `sources/softside-v1n05/LISTINGS.md`. The seventh batch (November 25, 2026) takes three listings from the sixth issue, Vol. 1 No. 6 (March 1979): Dive Bomb (with a computer bomber or gunner added), Jig Saw (with a two-player game added) and Tarot (a toy, with the card meanings written new); Fog Index (a tool, counting the words and syllables itself) followed on November 26, 2026; see `sources/softside-v1n06/LISTINGS.md`. The eighth batch (November 27, 2026) takes two listings from the seventh issue, Vol. 1 No. 7 (April 1979): Safari (with computer Bwanas and retiring at base added) and Rabbits and Foxes (a toy, with a meadow, a chart and animals released mid-run); see `sources/softside-v1n07/LISTINGS.md`. The magazine PDFs are kept locally only and are git-ignored.

Each prototype is Odin compiled to `js_wasm32`: `<game>/odin/game` holds the pure rules (native tests), `<game>/odin/web` the page layer, and `<game>/web/index.html` the page. `shared/` has the canvas/audio shim (`shim.js`, Odin package `proto:gfx`), the Public Pixel font (CC0, GGBotNet) and the LootLocker feedback shim.

```bash
tools/test.sh [game ...]          # native tests, then wasm builds
tools/build.sh [game ...] [--size] # build into build/web/<game>/ plus the hub page
tools/serve.sh                     # build everything, serve http://localhost:8010/ (no-cache)
tools/pages.sh                     # tests, size build, copy into docs/ for GitHub Pages
tools/make_shots.sh                # assets/screenshots/ (headless Chrome)
tools/make_cover.py                # assets/cover.png (630x500, from the screenshots)
./shippit.sh [--push]              # itch.io zip; uploads only with --push (see ITCH_DESCRIPTION.md)
```
